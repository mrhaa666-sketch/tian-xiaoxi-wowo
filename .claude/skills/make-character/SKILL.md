# 制作角色包

产出：一个 `角色名.json` 角色包，在游戏里「角色」→「导入角色包」（或「创建新角色」页最上面的「从角色包导入」）选它就能搬进来。格式说明见 `docs/角色包格式.md`。

## 1. 先问清楚

- **做谁**：已有作品里的角色（作品名 + 角色名），还是原创角色（一段描述）。
- **有什么图**，决定走哪条路：

| 手上的图 | 用的工具 | 效果 |
|---|---|---|
| 只有一张角色图 | `tools/image-pack.mjs` | 一张立绘，心情靠头顶的情绪标记表示 |
| 世界计划 Spine 渲染的整图（`face_*.png`、`pose_*.png` + `info.txt`） | `tools/sd-finished.mjs` | 每种心情一张图，说话换说话姿势，会眨眼 |
| 世界计划 Spine 的无五官身体 + 五官图 | `tools/sd-compose.mjs` | 身体 × 表情合成 |
| 没有图 | 不需要立绘 | 用代码画的占位小人 |

不要编造用户没给的图；图不够时按上表退到能做的那一档，并告诉用户。

## 2. 写设定

按 `docs/角色包格式.md` 的字段写，至少要有：`name`、`persona`、`schedule`、`profile`、`traits`、`skills`、`lore`。

- **已有作品的角色**：按原作的性格、经历、说话方式、人际关系写，不要和原作矛盾；原作没有的细节（作息、口味、喜欢的家具）按性格合理推断。只描述，不照抄原作台词。
- `persona`：150～300 字，写身份、性格、说话方式、在意的人和事、在家里会是什么样子。
- `schedule`：6～10 行「HH:MM 事情」，事情尽量用游戏里有的活动（起床、吃饭、工作、学习、看书、打游戏、做饭、画画、作曲、弹琴、看电视、洗澡、泡澡、睡觉）。
- `profile.likes` / `dislikes` 只能用文档里列出的食物 id；`lore.favoriteFurniture` 只能用文档里的家具 id；`lore.favoriteRoom` 用初始户型里有的房间名（客厅、厨房、浴室、书房、卧室A、卧室B、院子），不确定就留空。`lore.likedTags` / `dislikedTags` 只能用 `docs/家具包和房间包格式.md` 里「家具标签」列出的标签（喜欢 3～6 个，不喜欢 0～3 个）；`lore.heat` 按角色体质写 `cold` / `normal` / `hot`。
- `lore.presetRelations`：和其他会一起导入的角色之间的关系（名字对得上才生效，先导入谁都可以）。
- `traits` 0～100，`skills` 0～10。

游戏里也能让 AI 生成设定（「创建新角色」→「让 AI 帮你写设定」），需要用户先在设置里接上 AI。

## 3. 做立绘

立绘输出到 `public/packs/chars/<立绘名>/`（这个文件夹不进仓库）。立绘名只用小写字母、数字、下划线。

**一张图：**

```bash
node tools/image-pack.mjs --image <图片> --id <立绘名> --out public/packs/chars
```

图片不是透明背景、背景是纯色时加 `--nobg`。生成后看一眼 `avatar_normal.png`，头像应该是脸在中间；全身图会自动当全身处理（取上面一块做头像），半身图取中间。

**世界计划整图：**

```bash
node tools/sd-finished.mjs --in <解压后的文件夹> --out public/packs/chars --map 角色中文名=立绘名 --only 角色中文名
```

**世界计划身体 + 五官：**

```bash
node tools/sd-compose.mjs --skel <v2_sd_main.skel> --faces <五官文件夹> --bodies <身体文件夹> --out public/packs/chars --map 角色中文名=立绘名
```

个别姿势五官位置不准时，用 `--dy-<立绘名>-<姿势> <像素>` 手动微调，只改有问题的那一个。

## 4. 情绪标记（只有一张图时自动使用）

游戏里内置，用矢量画在头的右上角，不需要额外素材：

| 心情 | 标记 |
|---|---|
| 开心 | 带爱心的聊天气泡 |
| 生气 | 红色青筋（💢） |
| 害羞 | 往上飘的小爱心 + 腮红线 |
| 难过 | 头顶的阴沉竖线 + 眼泪 |
| 惊讶 | 黄色感叹号 |
| 生病 | 紫色晕眩螺旋 + 冷汗 |
| 困 | 往上飘的 Zzz |

整图立绘里缺某种表情时，也会用对应的标记补上。标记的样子在 `src/render/moodmarks.ts` 里改。

## 5. 打包

把设定写进一个 JSON（可以放在 `public/packs/` 下，比如 `public/packs/我的角色.json`，格式同 `docs/角色包示例.json`），然后：

```bash
node tools/make-pack.mjs --json <设定 JSON> --name <角色名> --sprites public/packs/chars/<立绘名> --out <输出的角色包.json>
```

## 6. 检查

- 用 `npm run dev` 打开游戏，在「角色」→「导入角色包」里导入生成的文件，看：立绘和头像对不对、各种心情（详情页「让TA生病（测试）」能看生病）、躺床和泡澡时露出来的头。
- 立绘和角色包里可能有别人的版权素材（比如世界计划的图）：只放在 `public/packs/`（已在 `.gitignore` 里）或发给用户，**不要提交到仓库**。
- 把生成的角色包文件发给用户，并说明怎么导入。
