# 家具包和房间包格式

在「建造」里点 **导入家具包 / 房间包** 选文件就能导入。家具包和房间包都是一个 JSON 文件，也可以写在同一个文件里（同时有 `furniture` 和 `rooms`）。

家里布置好的房间可以在「建造 → 导出…」里存成房间包，用到的自制家具会连图片一起带上，发给别人就能直接导入。

## 家具包

```json
{
  "format": "wowo-furniture-pack",
  "version": 1,
  "furniture": [
    {
      "id": "grand_piano",
      "name": "三角钢琴",
      "category": "音乐",
      "w": 2, "h": 2,
      "height": 90,
      "color": "#2d2a32",
      "standeeWidth": 200,
      "tags": ["音乐", "作曲", "古典", "高级感", "黑色"],
      "charLayer": "above",
      "interactions": [
        { "id": "play", "name": "弹钢琴", "pose": "sit", "minutes": [10, 90], "perMinute": { "mood": 0.3, "fun": 1 }, "tags": ["music"] }
      ],
      "images": { "base": "data:image/png;base64,…", "back": "data:image/png;base64,…" }
    }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `id` | 小写字母、数字、下划线。和内置家具重名时会自动加 `x_` 前缀 |
| `name` | 显示的名字 |
| `category` | 建造菜单里的分类，可以自己起名（不写就是「自制」） |
| `w`、`h` | 占几格（1～4） |
| `height` | 没有图片时占位图的高度（像素） |
| `color` | 没有图片时的颜色 |
| `standeeWidth` | 立牌宽度（像素），不写按占地格数估算（1 格约 96，2 格约 214） |
| `walkable` | `true` = 地毯这类能踩上去的 |
| `wallMounted` | `true` = 挂在后墙上的装饰 |
| `stairs` | `true` = 楼梯（能走到楼上） |
| `warmth` | 开着时让房间升高几度（取暖器 6、被炉 4） |
| `tags` | 家具标签，只能用下面列表里的（角色会喜欢/讨厌某些标签） |
| `charLayer` | 角色用这件家具时画在前面（`above`）还是后面（`below`）。不写就自动：坐/躺在上面时在后面 |
| `interactions` | 能做的事，见下表。不写就是纯装饰 |
| `images` | 图片：`base` 正面、`back` 背面、`on` 开着、`occupied` 有人躺着。都可以不写 |

**能做的事（interactions）**

| 字段 | 说明 |
|---|---|
| `id` | 小写字母、数字、下划线。`toggle` 表示开关（取暖器、灯） |
| `name` | 给主人和 AI 看的名字，比如「弹钢琴」 |
| `pose` | `stand` 站着、`sit` 坐着、`lie` 躺着、`use` 摆弄、`eat` 吃东西 |
| `onTop` | `true` = 人坐 / 躺到家具上面 |
| `minutes` | `[最短, 最长]` 游戏分钟 |
| `perMinute` | 每分钟对状态的影响：`hunger` 饱腹、`energy` 精力、`bladder` 如厕、`hygiene` 清洁、`fun` 娱乐、`social` 社交、`comfort` 舒适、`mood` 心情、`health` 健康 |
| `turnsOn` | `true` = 用的时候家具变成「开着」（用 `on` 图片） |
| `tags` | 行为标签：`rest` 休息、`work` 工作、`music` 音乐、`cook` 做饭、`eat` 吃饭、`warm` 取暖、`sick` 养病 |

**图片怎么做**：PNG，透明背景，正面稍微俯视的角度（和游戏里其他家具一样），宽 512 像素左右。用 `tools/make-furniture-pack.mjs` 可以把一个文件夹的图片自动塞进家具包：

```bash
node tools/make-furniture-pack.mjs --json 家具设定.json --images 图片文件夹 --out 家具包.json
```

图片按 id 命名：`grand_piano.png`、`grand_piano_back.png`、`grand_piano_on.png`、`grand_piano_occupied.png`。

## 房间包

```json
{
  "format": "wowo-room-pack",
  "version": 1,
  "rooms": [
    {
      "id": "music_room",
      "name": "音乐室",
      "w": 5, "h": 4,
      "floor": "herringbone",
      "wallStyle": "lilac",
      "furniture": [
        { "def": "upright_piano", "x": 0, "y": 0 },
        { "def": "guitar_stand", "x": 4, "y": 0, "flip": true },
        { "def": "rug", "x": 1, "y": 1 },
        { "def": "sofa", "x": 2, "y": 3, "back": true }
      ]
    }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `w`、`h` | 房间大小（格） |
| `floor` | 地板：wood、wood_dark、herringbone、tile、checker_pink、mint、mosaic、tatami、carpet、carpet_blue、carpet_lilac、marble、concrete、deck、grass、stone |
| `wallStyle` | 墙纸：cream、pink、sky、sage、lilac、peach、wood、brick、kitchen、night |
| `furniture` | 家具：`def` 是家具 id（内置的或者同一个包里的自制家具），`x`、`y` 是房间里的位置（左上角是 0,0），可选 `rot: 1` 转向、`back` 背对、`flip` 镜像 |
| `tiles` | 可选。不是方方正正的房间：只铺这些格子，`[{"x":0,"y":0,"floor":"wood"}, …]` |
| `walls` | 可选。精确的墙、门、窗：`[{"x":0,"y":0,"dir":"N","kind":"wall","style":"cream"}, …]`。`dir` 是 `N`（格子上边）或 `W`（格子左边），`kind` 是 `wall`、`door`、`window`。不写就自动围墙、南边开门 |

## 家具标签

- **感觉**：温馨、安静、热闹、浪漫、治愈、清爽、慵懒、神秘、梦幻、庄重、活泼、怀旧、高级感、孤独感
- **风格**：可爱、简约、北欧、日式、中式、复古、现代、工业风、田园、奢华、少女心、二次元、哥特、极简、古典、赛博朋克
- **材质**：木质、金属、布艺、皮质、玻璃、陶瓷、毛绒、藤编、大理石、塑料
- **颜色**：粉色、蓝色、绿色、紫色、白色、黑色、暖色调、冷色调、彩色
- **用途**：睡觉、休息、吃饭、做饭、学习、工作、阅读、音乐、作曲、唱歌、绘画、游戏、运动、洗漱、打扮、收纳、看电视、上网、喝茶、聊天
- **主题**：植物、自然、动物、猫咪、星空、夜晚、阳光、水、节日、户外、科技、书香、手作、零食、甜点、电子产品
- **体感**：柔软、暖和、凉快、舒服、宽敞、小巧、高大、亮、暗

内置家具都已经写好了标签。导入的家具没写标签的话，可以在「建造 → 管理自制」里让 AI 填，也可以自己点。

## 楼层

在「建造 → 家具 → 楼梯」放一个楼梯，楼上同一个位置会自动出现楼梯口。点画面上方的「1F」按钮切到楼上，接着铺地板、放房间。角色会自己走楼梯上下楼。房间包里也可以放楼梯（内置的「楼梯间」就是）。
