# 角色包格式

角色包是一个 JSON 文件，用来提前写好角色的全部设定，然后在游戏里一键导入。

- 导入：底部「角色」→「导入角色包」，选择 `.json` 文件。
- 导出：角色详情 →「人设」→ 页面最下面「导出成角色包文件」；或者「角色」→「导出全部角色」。
- 只导出设定，不导出聊天记录、记忆和当前的饥饿值等状态。
- 示例：[角色包示例.json](角色包示例.json)（两个原创角色，可以直接导入试试）。

除了 `name`，其他字段都可以不写，没写的用默认值。类型不对或超出范围的值会被忽略或截到范围内。

## 整体结构

```json
{
  "format": "wowo-character-pack",
  "version": 1,
  "characters": [ { "name": "……" }, { "name": "……" } ]
}
```

只有一个角色时，也可以直接写成一个角色对象 `{ "name": "……", ... }`。

## 角色字段

| 字段 | 说明 |
|---|---|
| `name` | 名字（必填，最多 20 字）。和家里已有角色重名时会自动加数字 |
| `persona` | 人设正文，AI 按这段扮演 TA |
| `schedule` | 作息表，每行「HH:MM 事情」，例如 `07:30 起床` |
| `profile.age` | 年龄 |
| `profile.birthday` | 生日，`MM-DD`。当天会有生日蛋糕和庆祝 |
| `profile.job` / `profile.hobbies` | 职业 / 爱好（爱好里写「画画」「打游戏」「做饭」等，TA 会更常去用相关家具） |
| `profile.likes` / `profile.dislikes` | 喜欢 / 讨厌的食物 id（见下表） |
| `traits` | 性格 0～100：`extraversion` 外向、`conscientiousness` 认真、`agreeableness` 随和、`neuroticism` 敏感、`openness` 好奇 |
| `skills` | 技能 0～10：`cooking` 做饭、`music` 音乐、`art` 画画、`gaming` 游戏、`study` 学习、`fitness` 运动 |
| `appearance` | 占位小人的颜色：`skin` `hair` `outfit` `accent` `eyes`（`#rrggbb`），`hairStyle` 0～3。有立绘时不用写 |
| `sprites` | 立绘。两种写法：写一个立绘名（小写字母、数字、下划线），游戏去 `public/packs/chars/<立绘名>/` 找图；或者写成 `{ "id": "立绘名", "files": { "文件名": "data:…;base64,…" } }`，把立绘直接打包进角色包，导入后存在浏览器里，换设备也只要这一个文件 |

### `lore`：更多设定

| 字段 | 说明 |
|---|---|
| `selfName` | TA 怎么称呼自己 |
| `callPlayer` | TA 怎么称呼你 |
| `speechStyle` | 说话方式 |
| `catchphrases` | 口头禅（数组，偶尔才说） |
| `backstory` | 背景故事 |
| `goals` / `fears` | 目标愿望 / 害怕的东西 |
| `likesTopics` / `dislikesTopics` | 喜欢 / 不想聊的话题 |
| `habits` | 生活习惯 |
| `chronotype` | 作息类型：`early` 早起型、`normal` 普通、`night` 夜猫子 |
| `sickBehavior` | 生病时：`rest` 乖乖休息、`stubborn` 硬撑、`clingy` 撒娇找人照顾、`normal` 看情况 |
| `conflictStyle` | 吵架时会怎样 |
| `favoriteRoom` | 最喜欢的房间名（和户型里的房间名一致才生效，例如「书房」「客厅」） |
| `favoriteFurniture` | 最喜欢的家具 id（数组），TA 会更常去用 |
| `likedTags` | 喜欢的家具标签（数组），见 `家具包和房间包格式.md` 里的标签表。用到、待在有这些标签的家具旁边心情会变好，也更常去用 |
| `dislikedTags` | 不喜欢的家具标签（数组） |
| `heat` | `cold` 怕冷 / `normal` 普通 / `hot` 怕热。影响 TA 觉得冷不冷 |
| `presetRelations` | 和其他角色的初始关系：`[{ "name": "名字", "affinity": -100～100, "note": "一句印象" }]`。家里有这个名字的角色时生效 |
| `custom` | 其他设定：`[{ "key": "名称", "value": "内容" }]`，原样告诉 AI |

## 这些设定在游戏里怎么起作用

- **AI 模式**：所有设定都会写进 AI 的提示词。
- **本地模拟模式**：作息类型、生病反应、最喜欢的家具和房间、爱好、技能、口味、性格都会参与「想做什么」的打分；口头禅会出现在聊天里。

## 只有一张图的角色

游戏里「创建新角色」→「上传图片」就行；离线做角色包用：

```bash
node tools/image-pack.mjs --image 角色图.png --id 立绘名 --out public/packs/chars
```

背景不透明、是纯色时加 `--nobg`。只有一张图时，心情用头顶的情绪标记表示（开心的爱心气泡、生气的红色青筋、害羞的小爱心、难过的眼泪、惊讶的感叹号、生病的晕眩螺旋、困的 Zzz）。

完整的制作流程见 `.claude/skills/make-character/SKILL.md`。

## 把立绘打包进角色包

用 `tools/sd-compose.mjs` 合成好立绘以后（输出到 `public/packs/chars/<立绘名>/`），运行：

```bash
node tools/make-pack.mjs --json public/packs/你的角色包.json --name 角色名 --sprites public/packs/chars/立绘名 --out 角色名.json
```

得到的 `角色名.json` 就是一个完整的角色包：设定和立绘都在里面，在「角色」→「导入角色包」里选它即可。游戏里「导出」时，有立绘的角色也会把立绘一起导出。

## 本地角色包列表（可选）

在 `public/packs/` 里放角色包文件和一个 `index.json`，「角色」页会出现一键导入按钮。这个文件夹不会提交到仓库，适合放只给自己用的角色：

```json
[
  { "name": "林栖和团团", "file": "example.json" }
]
```
