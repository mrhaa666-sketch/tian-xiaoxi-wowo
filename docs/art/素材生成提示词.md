# 恬小溪窝窝 · 素材生成提示词（GPT 生图用）

这份文档包含 8 个「素材包」：家具 4 包、状态图 1 包、地板、墙纸、食物各 1 包。
每个素材包是一整段提示词，复制下面代码框里的全部内容发给 GPT 即可，GPT 会把整包画完后打包成一个 zip 给你下载。

## 使用方法

1. **准备画风参考图**：一张《世界计划》区域小人的截图（透明背景或干净背景都可以）。每个素材包发送时都把这张图作为附图一起发。
2. **一次只发一个素材包**：把代码框里的内容整段复制发给 GPT，同时附上参考图。
3. **画不完时**：一包有十几张图，GPT 可能一次画不完。它停下时回复「继续画下一批，画完后统一打包」。
4. **打包**：全部画完后，如果 GPT 没有主动打包，回复「把这一包所有图片按文件名打包成 zip 给我下载」。如果它说做不到打包，就逐张下载，按文件名重命名。
5. **画风不统一时**：把这一包里你最满意的一张也作为附图，回复「以这张为准，重画 xxx.png，保持完全一致的画风」。
6. **状态图（素材包 E）**：要等对应的普通图画好之后再做，发送时把普通图一起附上。
7. **放进游戏**：解压后，家具放 `public/assets/furniture/`，地板放 `public/assets/floors/`，墙纸放 `public/assets/walls/`，食物放 `public/assets/food/`。

画布尺寸说明：横图 = 1536×1024，竖图 = 1024×1536，方图 = 1024×1024。
