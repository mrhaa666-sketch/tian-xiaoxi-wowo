# 恬静小窝 · 角色立绘包提示词（GPT 生图用）

每个角色要做 3 个图包（第 4 包动作立牌暂时不做），按顺序来。前一个包的成品是后一个包的「锚点」，所以要一个一个做，不要同时开。

| 包 | 内容 | 张数 | 必需吗 | 用在哪里 |
|---|---|---|---|---|
| 1 设定图 | 正面、侧面、背面三视图 | 1 | 必需 | 只当后面几包的参考，不进游戏 |
| 2 基础立牌 | 站（正/背）、走路侧面两帧、坐（正/背） | 6 | 必需 | 房子里走来走去的小人 |
| 3 表情头像 | 表情胸像，挑几种做就行 | 1～8 | 至少 face_normal | 头像、聊天、角色详情 |
| 4 动作立牌 | 吃饭、看书、看手机、生病、打盹、打招呼 | 6 | 暂时不做 | 做这些事时替换基础立牌 |

缺的图会自动兜底：
- 表情只有 `face_normal.png` 是必需的。缺哪种表情就显示 `face_normal`。
- 表情图可以从别处截取（比如从你已有的图里截），不一定用下面的提示词生成。文件名对上就行，尺寸、留白不用管，导入时会自动裁成统一的正方形头像。
- 基础立牌一张都没有时，继续用现在代码画的占位小人。

表情的文件名：`face_normal` 平常、`face_happy` 开心、`face_sad` 难过、`face_angry` 生气、`face_surprised` 惊讶、`face_shy` 害羞、`face_sick` 生病、`face_sleepy` 困。只做一部分时，建议优先 normal、happy、sad、sick、sleepy，这几种出现得最多。

## 使用方法

1. **先定好角色的英文 id**：只用小写字母、数字和下划线，例如 `xiaoxi`。所有文件放在这个名字的文件夹里。
2. **每个包都附上这些参考图**：
   - 角色本人的官方立绘或设定图（越清楚越好，最好有全身）；
   - 一张你想要的 Q 版小人画风参考图；
   - 家具 A 包里的 2 张成品（推荐 `sofa.png`、`armchair.png`），让小人和家具的线条、上色一致；
   - 从第 2 包开始，再附上第 1 包的 `turnaround.png`；第 3、4 包再附上第 2 包的 `stand_front.png`。
3. **填角色描述**：提示词里的【角色】一段要你自己改成这个角色的样子（发型发色、瞳色、衣服、配饰、性格气质）。写得越具体，每张图越统一。
4. **画不完时**：回复「继续画下一批，画完后统一打包」。
5. **某张不像时**：附上你最满意的一张，回复「以这张为准，重画 xxx.png，脸、发型、衣服、比例必须完全一致」。
6. **放进游戏**：解压到 `public/packs/chars/<角色 id>/`，然后在这个角色的角色包 JSON 里加一行 `"sprites": "<角色 id>"`。这个文件夹不会提交到仓库。

画布尺寸：竖图 = 1024×1536，横图 = 1536×1024，方图 = 1024×1024。

```
衣服：（填，例如：宽松的奶白色毛衣，深灰色百褶短裙，黑色过膝袜，棕色短靴）
配饰：（填，没有就写「无」）

【画风】

- 线条和上色要和那两件家具一致：干净细腻的细线稿，线条颜色比填充色深一些（深棕、深灰蓝），不用纯黑；柔和的赛璐璐平涂加轻微渐变，亮部有小块白色高光，暗部用偏冷的淡紫灰；色彩明亮、偏粉彩。

【内容】
turnaround.png｜横图｜同一个角色并排站成三个：左边正面、中间侧面（脸朝右）、右边背面。三个人大小完全相同，脚底在同一条水平线上，表情平静，双手自然垂下。背景透明，不要文字、不要地面、不要投影。

【交付】

```

## 世界计划小人：从 Spine 模型渲染表情头像

世界计划的区域小人是 Spine 4.1 骨骼模型：所有角色共用一个骨骼文件 `v2_sd_main.skel`，每个角色另有一套皮肤贴图（文件夹名像 `v2_sd_18mafuyu_casual`，里面有 `sekai_atlas.atlas.txt` 和 `sekai_atlas.png`）。把骨骼文件和要做的角色的皮肤文件夹一起打包发给 GPT，再发下面这段提示词。

表情和动画的对应关系：

| 文件 | 表情 | 用的动画 |
|---|---|---|
| face_normal | 平常 | idle01 |
| face_happy | 开心 | joy01（备选 laugh01） |
| face_sad | 难过 | sad01 |
| face_angry | 生气 | angry01 |
| face_surprised | 惊讶 | surprise01 |
| face_shy | 害羞 | 没有专门的动画，从 doubt01 和 listen01 里挑 |
| face_sick | 生病 | sad02（没有就 sad01），挑最没精神的一帧 |
| face_sleepy | 困 | idle01 里眨眼闭眼的那一帧 |

动画名的格式是 `v2_<性别>_<风格>_<表情>01_f`：性别女生是 `w`、男生是 `m`；风格有 `normal`、`cool`、`cute`、`happy`、`pure`、`silent`、`adult` 等，挑最符合角色性格的。
