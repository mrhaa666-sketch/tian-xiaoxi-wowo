# 家具立牌 · GPT 生图提示词

目标画风：日系手游里「区域场景道具」那种可爱、干净、明亮的 Q 版道具插画。

## 用法

1. 每次生成时，先粘贴「通用画风」，再粘贴下面某一件家具的描述。
2. 第一件建议先做**沙发**，满意后把它当成「画风锚点」：之后每次生成都附上这张图，并加一句「和附图保持完全一致的画风、线条粗细、上色方式和视角」。
3. 如果你手上有喜欢的参考截图，第一次生成时一起附上，说「参考附图的画风」。
4. 画布尺寸按每一项后面写的选：横图 1536×1024、竖图 1024×1536、方图 1024×1024。
5. 生成后检查：背景是否真的透明、有没有多余的地面和影子、物体是不是正对镜头。
6. 文件按「文件名」一栏命名，放进项目的 `public/assets/furniture/` 文件夹。

## 通用画风（每次都先粘贴这一段）

```
日系手游场景道具插画，Q 版可爱风格。
线稿：干净细腻的细线，线条颜色比物体本身颜色深一些（深棕、深灰蓝等），不用纯黑。
上色：柔和的赛璐璐平涂加轻微渐变，亮部有小块白色高光，暗部用偏冷的淡紫灰色。色彩明亮、偏粉彩但不发灰。造型圆润，边角带一点圆角，比例略微矮胖可爱。
视角：镜头在物体正前方、稍微偏高的位置往下看，能看到一点点顶面，看不到左右侧面。物体正对画面、左右基本对称，不要斜着摆。
光源：统一来自左上方。
构图：画面里只有这一个物体，水平居中，底部贴近画面下边缘，四周留少量空白。
背景：完全透明。不要地面、不要投影、不要文字、不要边框、不要其他装饰物。
```

## 常见问题

- **背景不透明**：补一句「请重新生成，背景必须是透明的 PNG」。
- **出现了侧面或者斜着摆**：补一句「物体必须正对镜头，只能看到正面和一点点顶面，不能看到侧面」。
- **前后两张画风不一样**：把满意的那张当附图，补一句「和附图保持完全一致的画风」。
- **「开」和「关」两张对不齐**：生成「开」的那张时，把「关」的那张作为附图，说「在这张图的基础上只改动……其他地方完全不变」。
