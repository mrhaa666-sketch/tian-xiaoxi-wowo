# 恬小溪窝窝

AI 驱动的生活模拟游戏。你以上帝视角看着一个可以无限扩建的家，角色们由 AI 决定去哪里、做什么、说什么，会和家具互动、彼此聊天、闹点小矛盾，也会主动找你说话。

现在是电脑上的第一版，画面用的是占位图形，以后会换成正式素材并打包成安卓应用。

## 在电脑上运行

需要先安装 [Node.js](https://nodejs.org/)（20 或更新版本）。

```bash
git clone https://github.com/mrhaa666-sketch/tian-xiaoxi-wowo.git
cd tian-xiaoxi-wowo
npm install
npm run dev
```

然后在浏览器打开 http://127.0.0.1:5173 。

## 怎么玩

- **看角色**：点画面里的角色或左边的列表，右边会显示 TA 的状态、想法、关系和记忆。
- **聊天**：在「聊天」页打字。角色会按人设回复，也可能照你说的去做（或者不听）。
- **喂饭**：选一样食物点「喂饭」，饭会放到最近的餐桌上，角色自己决定什么时候去吃。
- **生病**：角色偶尔会生病，按人设反应。逞强去工作的话，可以点「赶回床上休息」。
- **调解矛盾**：角色闹矛盾时，左下角会出现提示，写一句话去劝劝。
- **创建角色**：左边「创建新角色」，写下人设和作息表。作息到点时角色会收到提醒，由 AI 决定要不要照做。
- **建造**：右上角「建造」，可以放预设房间、铺地板（拖动铺一片）、砌墙、开门窗、摆家具。右键或两指拖动画面，滚轮缩放。
- **时间和节日**：跟随现实时间。公历和农历节日当天，角色会知道并有所反应。
- **新闻**：角色看电视、上网时会读到你设置的 RSS 新闻源，形成自己的看法。可以设置屏蔽词。

## 接入 AI

默认是「本地模拟」模式：不联网、不花钱，角色按简单规则生活。要让角色真正由 AI 驱动，打开「设置」：

- **Claude**：填 Anthropic 的 API Key。日常行为默认用 `claude-haiku-5-5`（便宜、快），聊天默认用 `claude-opus-5-5`。
- **兼容 OpenAI 格式的服务**：DeepSeek、通义、本地 Ollama 等，填服务地址、Key 和模型名。

费用控制：
- 角色只在「有事发生」或「手上的事做完了」时才问 AI，走路、使用家具这些都在本地完成。
- 「每分钟最多调用」默认 6 次，超出时角色改用本地规则行动。
- 两个角色连续聊太多轮后，会被提示自然结束对话。

API Key 只保存在你这台电脑的浏览器里。

## 项目结构

```
src/
  core/     数据结构、时间和节日、网络请求
  world/    地图、寻路、家具目录、预设房间
  sim/      角色的需求、生病、动作执行；事件、日志、存档
  ai/       AI 接入、提示词、调度、本地模拟、新闻
  render/   等距画面（PixiJS）、角色画法
  ui/       界面
```
